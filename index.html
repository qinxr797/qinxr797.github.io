Shopee 菲律宾站选品分析工具

个人项目 · Chrome 扩展 · 已迭代两代 2026-08 ~ 至今

A问题

想做菲律宾站的家居清洁类目，手工翻竞品评论太慢：一个词下几十个商品，每个几百条评论，还混着物流、发错货这类和产品无关的抱怨，看不出该改什么。

B做法

  1. 差评找机会：抓竞品 1 到 3 星评论按问题聚类，只算对得上具体商品的
  2. 需求验证：接 Google Trends 看菲律宾搜索趋势，历史已售和近期销量分开看
  3. 单位经济：采购、物流、佣金、广告、退款损耗，必填项缺一个就不出数
  4. 决策规则：确认差评不到 10 条只观察，利润低于 20% 不申请样品

C结果

  • 20 分钟归类完 522 条差评，引用的原话逐条回原评论核对
  • 51%的产品差评（446 条中 228 条）集中在两个可改的问题，直接变成打样方向
  • 6 张小红书图卡一键导出，数据可直接导入差评工作台出稿

02

电脑调优助手

个人项目 · GitHub 开源（MIT） · Windows 10 / 11 2026-09

A问题

两个朋友觉得电脑变慢了，又怕网上的「优化大师」乱改。他们要的是：双击即用，改了什么说得清，改坏了可还原。第一版给朋友试用后，又收到「运行起来有点卡」的反馈。

B做法

  1. 每项写清代价：是什么、有什么用、代价是什么、怎么还原，不写「一键加速」
  2. 按人给结论：同一项对竞技射击、3A、办公、老机器等 8 类人分别下结论
  3. 还原用原值：改之前先存这台电脑的原值，激进选项默认不勾，读不到的数据直接留空、不编数
  4. 先测再改：朋友说卡，先量每页出第一帧和后台刷新的耗时，把读传感器这类慢操作挪到后台，改完用同一套方法再量

C结果

  • 65 × 8个优化项乘 8 种使用场景，每类人的结论单独写
  • 14 倍启动时界面构建合计从 13.9 秒降到 0.97 秒
  • MIT源码公开在 GitHub，双击 exe 即用，不联网不常驻

拼多多「像素装备铺」店铺运营

毕业设计 · 4 人团队 2026-03 ~ 2026-04

A问题

4 人团队从 0 开拼多多店，卖像素风拼豆玩具。新店起号期没有自然流量，要靠短视频和直播把人拉进来、留下来，还得知道观众是在哪一步走掉的。

B做法

  1. 选品有依据：团队前期调研定下拼豆为主推品类，避开和乐高、迪士尼正面竞争
  2. 我的分工：短视频拍摄、起号期直播出镜、直播数据复盘，执笔团队《调研报告》
  3. 逐场复盘：8 场直播每场从直播罗盘导出后台数据，按「进房、停留、互动、关注」一层层找流失点
  4. 落到方案：用「关注领图纸」给观众关注的理由，用投票选配色、抽奖带动互动

C结果

  • 43.1%8 场直播进房率均值，单场峰值 77.1%
  • 3.2 分钟观众人均停留时长
  • 86 单团队带动订单，好评率 97.2%

小红书内容运营 Agent（差评工作台）

个人项目 · 桌面应用 · 基于开源项目 Easel 二次开发 2026-10

A问题

选品工具跑出的差评数据，要写成小红书和抖音的稿子、配图卡、核对数字。步骤多，手工做容易把数字写错。

B做法

  1. 在开源项目上做减法：拉 Easel 原代码，砍掉账号、自动发布等用不上的部分
  2. 接上选品工具：导入整包 JSON，自动建选题卡
  3. 按规矩写稿：AI 按「读翻测判」四步写三个平台的稿
  4. 发前预检：自测栏三题、数字核对，百分比只认导入数据里的数

C结果

  • 2.5 分钟从导入数据到三个平台的稿
  • 8 张图卡自动生成，选为配图
  • 1 个发布包：各平台文本加按序号的配图
运行环境
Windows；便携 Node 24 + Python 后端，服务只绑本机 127.0.0.1
模型
DeepSeek（OpenAI 兼容接口）
关键机制
预检规则写在前端，数字对不上就算错；导入数据只认插件导出的两种格式
怎么验证
全流程实测：导入、写稿、预检、出图、导出发布包

07

肌肉存钱罐

个人项目 · 微信小程序 2026-10

A问题

健身记录 App 大多要注册、带广告，训练计划、饮食和体重分散在几个地方。想要一个打开微信就能跟练、按自己体重算该吃多少的工具。

B做法

  1. 跟练：练几休一自动顺延，打勾记组数和重量，组间计时；器械被占一键换平替动作
  2. 动作库：接入开源动作图库，每个动作配起始和发力两张图、三条中文要点
  3. 饮食：按体重和训练日、休息日算三大营养素克数，记一天吃了什么
  4. 计划：自定义训练计划，也能导入文字计划、分享码和其他健身 App 导出的记录

C结果

  • 273 个动作配图和要点
  • 1.3 MB小程序包，动作图压成黑白线稿
  • 4 页训练、饮食、体重、计划，数据只存在手机本地

已发布体验版，正式上线在走备案和审核。
